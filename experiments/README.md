# 실험

## 실행

```
python experiments/mafia_pilot.py --check      # 1단계 파일럿: 기존 측정값 대조
python experiments/mafia_pilot.py              # 파일럿 전체 비교 → mafia_pilot.csv
python experiments/mafia_compare.py --check    # 6단계: 파일럿과 같은 조건(wary, all)의 봇 승률 대조
python experiments/mafia_compare.py            # majority/wary, 연결 2종, 난이도 3종, 조건당 1000판 → mafia_compare.csv
python experiments/mafia_compare.py --ai --runs 30   # ai 시민 포함 (LLM_API_KEY 필요, 없으면 건너뜀)
```

`mafia_compare.py`는 실제 엔진 코드(`god/game.py`, `city/logic.py`, `city/ai.py`)를 HTTP 없이 함수로 연결해 `player=bot` 게임을 돌린다. 조건마다 시드 고정.

## "알고 싶은 것"

1. AI 시민이 덜 속는가: 키 필요.
2. AI 시민이 마피아를 맞게 의심하는가: 키 필요.
3. 사람 마피아가 봇보다 잘 속이는가: 사람 데이터 필요. 봇 기준값은 위 표의 마피아 승률.
4. 정보 공유로 거짓말이 얼마나 빨리 들키는가: wary의 발각률·발각 턴 (위 표).

## 실험 C: 똑똑한 전략 대 봇 (`mafia_strategy.py`)

```
python experiments/mafia_strategy.py --check            # 자체 점검 (봇 전략 = 엔진 player=bot 재현)
python experiments/mafia_strategy.py                    # 난이도 × 시민(wary, majority) × 전략, 3000판 → mafia_strategy.csv
python experiments/mafia_strategy.py --tune --runs 2000 # 의심도 수치 후보 (wary) → mafia_strategy_tune.csv
```

전략 `smartL`: 화면 정보(정답, next_hints, next_share_pairs, 시민별 나에 대한 의심도)만 쓴다. 시민별 참/거짓 배정 16가지 중 이번 턴 뒤 내 의심도가 모두 L 미만인 배정에서 거짓말이 가장 많은 것을 고른다 (공유 쌍 모순 +20까지 계산). 안전한 배정이 없으면 최대 의심도가 가장 낮은 배정(힌트와 같은 말로 회복). 마지막 턴은 L을 투표 임계값으로 올린다. 연결 all, 전략끼리 같은 시드.

| 난이도 | 시민 | 봇 승률 | smart40 승률 | 봇 발각률 | smart40 발각률 |
|---|---|---|---|---|---|
| easy | wary | 0.584 (0.567~0.602) | 0.605 (0.588~0.623) | 0.414 | 0.386 |
| normal | wary | 0.229 (0.215~0.245) | 0.282 (0.266~0.298) | 0.675 | 0.025 |
| hard | wary | 0.022 (0.018~0.028) | 0.031 (0.026~0.038) | 0.948 | 0.016 |
| easy/normal/hard | majority | 1.000 / 0.519 / 0.239 | 같음 | 0 | 0 |

- 전략은 발각을 거의 없애지만 승률은 조금만 오른다 (normal만 구간이 안 겹침). 발각을 피해도 15턴에 시민 과반이 틀려야 이기는데, 시민 간 주장과 정확한 힌트가 대부분 이긴다.
- majority는 의심도·투표가 없어 항상 반대가 최선이라 전략이 봇과 같다. easy는 동료(항상 반대)가 들켜 팀이 지는 판이 많아 플레이어 선택의 몫이 작다.
