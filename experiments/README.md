## 실행

```
python experiments/mafia_pilot.py --check      # 1단계 파일럿: 기존 측정값 대조
python experiments/mafia_pilot.py              # 파일럿 전체 비교 → mafia_pilot.csv
python experiments/mafia_compare.py --check    # 6단계: 파일럿과 같은 조건(wary, all)의 봇 승률 대조
python experiments/mafia_compare.py            # majority/wary, 연결 2종, 난이도 3종, 조건당 1000판 → mafia_compare.csv
python experiments/mafia_compare.py --ai --runs 30   # ai 시민 포함 (LLM_API_KEY 필요, 없으면 건너뜀)
python experiments/mafia_botwin.py --check     # 화면·API의 봇 승률(시드 0~9999) 계산, backend 값과 대조
```

파일럿의 exp3 대조만 15턴으로 돌리고, 나머지 턴 수는 엔진의 `TURNS`(7)를 쓴다.

`mafia_compare.py`는 실제 엔진 코드(`god/game.py`, `city/logic.py`, `city/ai.py`)를 HTTP 없이 함수로 연결해 `player=bot` 게임을 돌린다. 조건마다 시드 고정.

## "알고 싶은 것"

1. AI 시민이 덜 속는가: 키 필요.
2. AI 시민이 마피아를 맞게 의심하는가: 키 필요.
3. 사람 마피아가 봇보다 잘 속이는가: 사람 데이터 필요. 봇 기준값은 위 표의 마피아 승률.
4. 정보 공유로 거짓말이 얼마나 빨리 들키는가: wary의 발각률·발각 턴 (위 표).

## 실험 C: 똑똑한 전략 대 봇 (`mafia_strategy.py`)

```
python experiments/mafia_strategy.py --check   # 자체 점검 (봇 = 엔진 player=bot, smart 의심도 예측 = 엔진 결과)
python experiments/mafia_strategy.py           # wary, 의심도 수치 후보 × 난이도 × 전략, 2000판 → mafia_strategy.csv
```

- 전략 `smart`: 화면 정보(정답, next_hints, next_share_pairs, 지난 시민 결정, 시민별 나에 대한 의심도)만 쓴다. 시민별 참/거짓 배정(최대 16가지)마다 `city.logic.game_turn`을 직접 불러 이번 턴 뒤 내 의심도를 예측하고, 모두 limit(= 임계값 − 20) 미만인 배정 중 거짓말이 가장 많은 것을 고른다. 안전한 배정이 없으면 최대 의심도가 가장 낮은 배정(힌트와 같은 말로 회복). 마지막 턴은 limit을 임계값으로 올린다.
- wary 시민, 연결 all만. majority 시민은 의심도·투표가 없어 항상 반대가 최선이라 전략이 봇과 같다.
- 전략·후보끼리 같은 시드 목록을 쓰지만 구간(Wilson 95%)은 독립 표본으로 계산했다 (짝 비교보다 보수적).
- 결과는 이 탐욕 전략 기준이지 사람이 낼 수 있는 상한이 아니다. 발각률 감소도 이 전략 기준이며, 플레이어 의심도를 임계값 밑에 둬도 다른 시민·동료 때문에 투표가 열리면 최고 의심 도시로 지목돼 들킬 수 있다.

수치 후보별 승률 (7턴, 봇 → smart, 괄호는 95% 구간, 발각률은 봇 → smart). 난이도는 spec 7.2 (쉬움 마피아 1 오류 0.48 / 보통 1, 0.4 / 어려움 1, 0.3):

- 7턴, 현재 수치: 봇은 normal에서 43%가 들키고 smart는 1.7%만 들키지만, 승률 차이는 작다. 구간이 안 겹치는 난이도는 hard뿐이고(0.078 → 0.129), easy·normal은 겹친다. 15턴 때는 세 난이도 모두 안 겹쳤다.
- 다름 +10, +5처럼 거짓말이 싸면 봇도 잘 안 들켜 smart가 봇보다 낫지 않다. (15턴 때 이전 +10 수치·난이도(쉬움 마피아 2 오류 0.4 / 보통 0.3 / 어려움 0.2)에선 normal 봇 0.230 → smart 0.276이었다. 7턴으로는 다시 재지 않았다.)
- 같음 −10/−5(신뢰 회복이 느림)는 전체 승률이 낮아진다. 모순은 봇 승률을 바꾸지 않고 임계값은 조금 바꾸며, 둘 다 smart의 이득 크기를 바꾼다 (normal 이득: 현재 +0.037, 모순 0은 +0.058, 임계값 40은 +0.076, 임계값 80은 +0.006).
